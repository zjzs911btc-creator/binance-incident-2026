# Binance Incident 2026

English / 中文

## Overview 概述

This repository contains a static web page designed to present the timeline and fund flow of the Binance incident in 2026. The project focuses on information clarity, narrative structure, and visual presentation for public understanding.

本仓库包含一个静态网页，用于展示 2026 年 Binance 事件的时间线与资金流向。该项目聚焦于信息清晰度、叙事结构和公开展示的视觉呈现。

## Project Goal 项目目标

- Present important events in a clear and readable timeline
- Visualize key fund movement and transaction relationships
- Provide a professional static page for public communication
- Support bilingual documentation in both English and Chinese
- Create a maintainable foundation that can be expanded in the future

- 以清晰易读的方式呈现关键事件
- 可视化展示资金流动与交易关系
- 提供面向公众沟通的专业静态页面
- 支持中英文双语文档说明
