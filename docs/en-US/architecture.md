# Architecture Overview

## 1. Overall Structure

The project is currently centered on a static page and is suitable for lightweight deployment and rapid presentation. The architecture is intentionally simple, with emphasis on information structure and page clarity rather than complex front-end engineering.

## 2. Core Components

- README: project description and overall positioning
- docs: bilingual documentation folders
- assets: static resources such as images and icons
- src: front-end code and page logic
- data: structured timeline and fund flow data

## 3. Future Expansion Direction

If the project grows later, it can gradually adopt:

- front-end framework (React / Vite)
- dynamic data loading
- interactive visual charts
- more complete internationalization support

## 4. Recommended Principles

- Keep the structure clear and avoid mixing responsibilities
- Separate static assets from logic
- Maintain ease of maintenance and future scalability
